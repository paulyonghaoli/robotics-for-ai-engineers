# Course I exam · Foundations of Embodied AI

**Covers:** Modules 0–3 · **Format:** cross-module, closed-book · **Time:** ~60 min · **Passing bar:** 80%

This exam deliberately mixes modules within single questions — the way real problems arrive. A frame bug (Module 1) surfaces as filter bias (Module 3); a control choice (Module 2) constrains an estimator (Module 3). If a question feels like it belongs to two lessons at once, that's the design.

Take it closed-book after finishing the [frame-transforms mini-project](modules/01-geometry/project-frames.md) and the [localization project](modules/03-estimation/project-localization.md). Score under 80%? The explanations name the lesson to revisit — go, then retake (answers shuffle).
