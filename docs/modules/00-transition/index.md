# Module 0 · From ML to Robotics

**Status:** Complete

Robotics engineering is ML engineering with three extra constraints: the system is **embodied** (outputs move mass through space), **closed-loop** (today's action changes tomorrow's input distribution), and **real-time** (a correct answer that arrives 200 ms late is a wrong answer).

## What this module covers

- The perception–estimation–planning–control loop, and where "the model" sits in it
- Offline metrics vs closed-loop metrics — why a better mAP can make a worse robot
- The robotics software stack, from drivers to behavior
- Common robotics roles (perception, autonomy, robot learning, platform) and which of your existing skills each one leverages
- Simulation vs physical hardware, and why this curriculum is simulation-first
- A mathematical-prerequisites diagnostic (linear algebra, probability, basic calculus)
